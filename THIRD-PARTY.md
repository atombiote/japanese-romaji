# Build-time tools

The resource pack contains pack.mcmeta, pack.png, NOTICE.txt, LICENSE.txt and assets/minecraft/lang/ja_jp.json. No tokenizer or dictionary is distributed inside it.

- [SudachiPy / Sudachi.rs](https://github.com/WorksApplications/sudachi.rs), version 0.6.10: Apache-2.0. Used for Japanese tokenization and readings.
- [SudachiDict](https://github.com/WorksApplications/SudachiDict), core dictionary 20250129: consult its Apache-2.0 license and LEGAL notices for dictionary sources.

PyKakasi was downloaded during tool evaluation; the final generator does not import it, and it is not a build requirement or pack dependency.

Build tools do not grant rights to Minecraft's original language assets. Rights in original project contributions are described in LICENSE.txt.
