## Coverage rules

The official 1.21.1 English file contains 6881 keys. Of these, 6506 available Japanese entries receive readings. Another 279 contain no Japanese script and three are language metadata. The installed Japanese file has no translation for 93 older keys; their existing English fallback is preserved. No replacement Japanese text is invented.

All current block/item/entity/effect/enchantment/biome names with Japanese text are covered, along with subtitles, menus, advancement text, commands and messages. Newer-version-only keys are excluded. Counts include aliases, descriptions, banner patterns and technical block variants, not just unique inventory items.

The exact exception key list is in data/coverage-exceptions.json. Only the Japanese language file is overridden. Text supplied by players, servers or other mods is outside this vanilla translation pack. Standalone game assets such as the English End Poem and splash text are outside the language-key scope.
