# Changelog

## 0.3.0-beta.1 - Full vanilla Japanese coverage

- Added atombiote's original header artwork and a matching pack icon.
- Added publisher/contact information and an All rights reserved notice for original contributions.

- Expanded to 6,506 annotated Japanese translation entries from the Java 1.21.1 key set.
- Added remaining items and blocks, creatures, biomes, effects, enchantments, advancement text, subtitles, menus, options and messages.
- Retained all 264 prior values.
- Added dictionary generation, Minecraft-specific corrections and reproducible build data.
- Preserved dynamic message placeholders without duplicating arguments.
- Added an exact original-text recovery audit and full per-category TSV lists.
- Left language metadata, non-Japanese strings and existing English fallbacks unchanged.
- Marked the release beta because independent Japanese proofreading and live UI checks are pending.


## 0.2.0 - Wood families

- Added 258 block-name overrides spanning all 11 wood families in Java 1.21.1, associated plant and wall-sign variants, and wooden storage/utility blocks.
- Retained all six sword translations from v0.1.0 without changing their values.
- Added long-vowel macrons where needed and a beginner explanation in the README.
- Checked translation keys against the SHA-1-verified official 1.21.1 client, excluding newer wood families and shelf blocks.
- Preserved every selected original Japanese label exactly.
- Added complete coverage and release metadata.
- Kept the previous v0.1.0 ZIP as a rollback option.

## 0.1.0 - Sword prototype

- Added Japanese readings for wooden, stone, iron, golden, diamond and netherite swords.
